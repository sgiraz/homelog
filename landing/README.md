# Landing page — homelog.dev

Static marketing page for HomeLog. **Work in progress.**

Single self-contained `index.html` (Tailwind via CDN) plus self-hosted fonts in
`fonts/` — no build step. Just publish the folder.

## Deploy on Render (static site)

1. New → **Static Site** → connect the repo.
2. **Build Command:** _(leave empty)_
3. **Publish Directory:** `landing`
4. Add custom domain **homelog.dev**.

Works the same on GitHub Pages, Cloudflare Pages or Netlify — it's just static
files served at the domain root.

## Notes

- Fonts are self-hosted under `fonts/`, generated by `node scripts/vendor-fonts.mjs`.
  Do not point them back at fonts.googleapis.com: that discloses every visitor's
  IP to Google with no legal basis, and the privacy policy states we don't.
- Tailwind still loads from `cdn.tailwindcss.com`, the last third-party request
  the page makes on its own: it exposes the visitor's IP to that CDN. Compile it
  to a local stylesheet before this is considered production-final. It is
  disclosed in the privacy policy meanwhile.
- The privacy policy for all three domains lives at `docs-site/privacy.md`
  (EN) and `docs-site/it/privacy.md` (IT); the footer links to the right one
  per language via `data-i18n-href`.
